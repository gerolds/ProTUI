# Design

The user owns everything in this folder. It is the only source of game design.

- `treatment.md`: the source design. The user adds it; agents do not write it.
- `steering.md` (optional): the user's later requirements and lessons. Read it before implementing game behavior.
- `iteration.md` (created at the first experiment): question, hypothesis, playable command, observed player actions, interpretation, keep/change/remove decision, next test.

The template's bones and guidance carry no game design. Do not import rules, genre, layouts or progression from other projects.
